How to create react app?

Watch here!

Summary

React need Nodejs to run

Check version nodejs: node -v

Create React app: npm create vite@latest

Change folder: cd nameFolder

Run app: npm run dev
(Note: need to be placed directly in the correct React project folder)

Commands to run app when downloading a file from Git: npm install

Giải thích từng phần cấu trúc dự án React+Vite

Một dự án React + Vite có cấu trúc khá gọn gàng vì Vite là công cụ build nhẹ và nhanh, thường dùng thay cho Create React App. Dưới đây là cấu trúc cơ bản và ý nghĩa từng phần.

1. Cấu trúc cơ bản

my-react-app/
│
├── node_modules/
├── public/
│   └── vite.svg
│
├── src/
│   ├── assets/
│   ├── components/
│   ├── App.jsx
│   ├── main.jsx
│   └── index.css
│
├── index.html
├── package.json
├── vite.config.js
└── .gitignore

2. Giải thích từng phần

1️⃣ node_modules

  • Chứa toàn bộ thư viện đã cài bằng npm hoặc yarn
  • Ví dụ:
    • React
    • React DOM
    • các library khác

    • 📌 Thư mục này không nên chỉnh sửa trực tiếp

2️⃣ public/

Chứa file tĩnh (static files).

Ví dụ: 
public/
   vite.svg
   images/
    Các file trong đây:
  • không bị Vite build lại
  • có thể truy cập trực tiếp bằng URL

3️⃣ src/ (Quan trọng nhất)

Đây là source code chính của ứng dụng React.

src/
 ├── assets/
 ├── components/
 ├── App.jsx
 ├── main.jsx
 └── index.css

assets/: Chứa tài nguyên như: ảnh, icon, font

components/: Chứa các React component tái sử dụng.

App.jsx: Đây là component gốc của ứng dụng.

main.jsx: Đây là entry point của React.

index.css: CSS toàn cục của ứng dụng.

4️⃣ index.html

File HTML chính của project.

5️⃣ package.json

6️⃣ vite.config.js

7️⃣ .gitignore

8️⃣ dist/ (sau khi build)
