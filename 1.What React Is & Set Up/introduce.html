What is React?

React is a front-end JavaScript library.

React was developed by the Facebook Software Engineer Jordan Walke.

React is also known as React.js or ReactJS.

React is a tool for building UI components.

How does React Work?

React creates a VIRTUAL DOM in memory.

Instead of manipulating the browser's DOM directly, React creates a virtual DOM in memory, where it does all the necessary manipulating, before making the changes in the browser DOM.

React only changes what needs to be changed!

React finds out what changes have been made, and changes only what needs to be changed.

You will learn the various aspects of how React does this in the rest of this tutorial.

Virtual DOM in React

The Virtual DOM in React is an in-memory, lightweight JavaScript representation of the actual DOM. Instead of directly manipulating the real DOM — which is slow for frequent updates — React updates this virtual copy first, then efficiently syncs changes to the real DOM.

When your app’s state or props change, React follows a specific process:

  1. Initial Render – React builds a virtual DOM tree representing the UI.
  2. State/Props Update – A new virtual DOM tree is generated to reflect changes.
  3. Diffing Algorithm – React compares the new tree with the previous one to find the minimal set of changes.
  4. Reconciliation – Only the affected parts of the real DOM are updated.
  5. DOM Update – The real DOM is patched with these changes, avoiding full re-renders.
